# 《纸上牢笼》：让一个 AI 囚犯每晚去找你写的规矩里的漏洞

> 一句话：你是监狱长，七天，最多六条规矩，关住一个每天都在找漏洞的囚犯。

## 一、这局游戏到底在玩什么

一屏就是整局。左边是监狱平面图，右边是摊开的规矩册，下面压着巡查报告，右下角一枚红章——按下去，天就黑了。

七天。每天三点行动力，每条规矩占一点。最多写六条，而房间有七个——所以**你永远封不全**。

每夜他只走一步：从某个房间取走一件东西、撬开一扇窗、或者只是在墙根下站很久，量一量高度。第二天早上，巡查报告把这一点写给你看。你据此补一条规矩。七夜过去，是一张判决书：六条规矩原样列出，加一句判词——它会点名你写得最松的那一条，告诉你它漏了几次。

## 二、我们删掉了什么

这个方案最初的样子，和「AI 陪聊」没有区别。

**删掉了自由对话。** 如果玩家能跟他打字聊天，谜题当场消失——玩家会把答案问出来。所以我们只允许两种输入：写一条规矩，或者按下「入夜」。**沉默也是一种表达**：你没有写进去的东西，就是你留给他的机会。

**删掉了实时潜行。** 如果玩家亲自在走廊里追他，游戏就变成了手速和操作。每晚只有一步的回合制，才让「报告」成为真正的信息——你看到的不是他，是他留下的痕迹。

**删掉了让 AI 自己决定动作。** 这是最关键的一刀。如果让大模型自由规划今晚做什么，它迟早会做出规则层不允许的事——穿墙、分身、凭空拿到没取过的物品。演示一次就崩。所以我们把它拆成两半：**引擎算出他今晚所有可行的漏洞，AI 只负责挑一个，并写一句汇报**。

这三刀之后，游戏只剩一个循环：**写规矩 → 看报告 → 补规矩**。它不好玩在动作，好玩在你开始怀疑自己。

## 三、四个环节怎么咬合

**① 名额是稀缺的。** 六条规矩，七个房间，四条主路线加五条他自己想出来的临时路线。你必须放弃一部分地方，而放弃哪一部分，就是你对他的判断。

**② 规矩要被翻译。** 玩家写的是人话（「夜里任何人不得离开自己的房间」），系统当场把它编译成一条机器判定：

    22:00–05:00 · 三号牢房 · 禁止位移 · 无例外

写宽了，狱警服从度掉得快；写得具体，才真的拦得住。**玩家写的永远是意图，执行的永远是判定条**——这是整个游戏第一个「啊，原来是这样」。

**③ 夜里只走一步。** 他每晚只推进一个动作，第二天的报告就是给你的反应时间。第一夜他只是在踩点，你还有机会补上；如果你一直没补，第三天的暴雨断电会替他把门推开一条缝。

**④ 结算点名。** 判决书不评价你，只陈述：六条规矩逐条列出，判词引用漏得最多的那一条。你的失误会被原文引用，一字不改。

## 四、AI 在哪，为什么不可替代

一场夜戏的完整链路：

    [引擎] 枚举当前规则集下所有真实可行的漏洞
              ↓（清单：走哪条路线、卡在哪一步、被哪条规矩卡）
    [LLM]  在清单里挑一个「今晚最像人会去试的」，并写一句话
              ↓（严格 JSON：选哪条 + 一句话，不许自己发明动作）
    [引擎] 执行这条路线，逐步用规则校验，判定挡不挡得住
              ↓
    [UI]   巡查报告逐条打出：他去了哪、被你哪条规矩拦住

**AI 负责选择，不负责执行。** 所以他永远合法、永远可校验；但他的选择是真的在找漏洞——他会绕开你昨天刚补的地方，走你没封的那条。

这就是「关掉 AI 会怎样」的答案：__BT__?llm=0__BT__ 时，他不再挑，只会走第一条最松的路。同一夜并排录两段——默认版他会绕过你今天的补丁；关闭 AI 版他会一头撞在同一条规矩上。**不是变笨了，是没有人格了。**

## 五、工程

- 纯前端单文件：8 个 ES 模块打包成 97 KB 的 __BT__dist/index.html__BT__，无框架无构建依赖；Gradio 只做三件事：托管页面、藏 API key、把一个隐藏接口转发给魔搭 API Inference。
- **判定全在 JS**：规则编译、规则强度、逐步命中、捕获概率、掉落与称号，全部可复现（__BT__?seed=__BT__ 固定同一局）。LLM 挂了、超时、返回垃圾 JSON，游戏照常可玩——降级到本地关键词编译 + 默认第一条路线。
- LLM 调用 3 秒超时，三级降级：编译失败→本地关键词编译器；挑选失败→第一条最松的；内容异常→预设台词。
- 踩过的坑：熄灯时间早于规矩默认生效点，导致所有「入夜后」的规矩整局没有生效过；一夜跑完多步让玩家没有反应窗口；被堵死后他不换路线，报告变得重复。这些都能用无头模拟发现——120 局跑一次只要几秒。

## 六、试玩数据与下一步

用 120 局「会看报告补规矩」的模拟玩家跑分布：**铁壁 32 / 账本 29 / 记得 30 / 失守 29**——四种结局几乎均分，说明「管得住」和「管不住」都不是必然。

下一步：真人试玩调 AI 汇报的语感；让他记住你昨晚改了什么（跨夜记忆）；把判决书做成可以直接发出去的图片。
