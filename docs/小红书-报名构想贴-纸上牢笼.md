## 正文（约 640 字，可直接复制）

我做了一款小游戏，叫《纸上牢笼》。

**【游戏创意】**
你是监狱长。七天，最多六条规矩，关住一个每天夜里都在找漏洞的囚犯。
他不是随机乱走的 NPC——他会看你写的规矩，挑一条你没盖住的路。你写的每一条规矩，第二天都可能变成他用来对付你的依据。

**【核心玩法】**
一屏就是一整局，大概 8 分钟。
· 写规矩：用一句人话写，系统把它译成一条能执行的条件。「夜里任何人不得进入洗衣房」→ 22:00–05:00 · 洗衣房 · 禁止位移 · 无例外。
· 入夜：他每晚只走一步。你合上案卷，天就黑了。
· 读报告：第二天早上的巡查报告，会告诉你他走到了哪、走了哪条缝。
· 补规矩 / 下注：写窄了才拦得住，但规矩只有六条；写宽了狱警先不服从。入夜前还可以猜他今晚走哪条路，猜中多 1 点行动力。
· 结算：第七夜之后是一张判决书，只陈述事实——哪条规矩漏了几次、他是从哪条缝出去的。四种称号：铁壁 / 空规矩 / 账本 / 记得。

**【计划使用的 AI 工具】**
· 玩法内 AI：魔搭 API Inference，Qwen3.8-27B（关掉思维链）。它做三件事：把你的话编译成判定条；在引擎算出的「漏洞清单」里挑一条今晚最像人会走的路，并说清理由；写一句他此刻的独白。**判定全部由规则引擎算，AI 只能提案，非法动作当场驳回。**
· AI 的记性：它记得自己怕什么、哪条规矩拦过它几次、哪条漏过、昨晚走到第几步，敌意和服从度也会影响它挑哪条路。第二天报告里会出现一行「他挑这条路，因为：……」。
· 可关掉的对照：在链接后面加 ?llm=0，同样的六条规矩，他会退化成「按顺序试第一条最松的路」，独白变成模板。判定一次都没变——变的是他像不像一个人。
· 写代码：AI 编程 Agent 写了约九成代码；我负责定机制、砍功能、做平衡。整屏是手写 SVG + CSS，没有游戏引擎、没有外部美术素材；音效是程序化合成的。

**【预期呈现形式】**
网页 Demo，已部署在魔搭创空间：手机竖屏一屏一局，不用注册，点开就能玩。代码 Apache-2.0 开源。后续按试玩反馈调数值、加路线。

七天之后，判决书上会写你的名字，还有一句：是哪一条规矩放他走的。
