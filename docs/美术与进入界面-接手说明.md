## 2. 硬契约（改封面必须满足）

`ui/intro.js` 必须导出两个函数，返回值是**完整 SVG 字符串**（`<svg ...>...</svg>`）：

```js
export function renderIntro()        // 桌面：viewBox 必须是 "0 0 1600 1000"
export function renderIntroMobile()  // 手机竖屏：viewBox 必须是 "0 0 800 1840"
```

四条不可破坏的约束：

1. **必须有一个 `data-act="start"` 的元素**（现在的红章）。`ui/app.js` 用 document 级事件委托，点它才开始新一局。可以是 `<g>`、`<rect>`、`<button>` 包在 SVG 里。
2. **viewBox 尺寸不能变**。手机壳用 `aspect-ratio: 800 / 1840` 把整屏缩放进视口；改了比例手机就会被裁。
3. **纯前端、无网络请求、无外部字体/图片 URL**（创空间是 iframe 内嵌，外链会被拦；打包也是单文件）。图片要内联成 base64 data URI。
4. **不要在 intro.js 里访问 `document` / `window` / 游戏状态**。它是纯函数：进参无、出参字符串。要动效就写 SVG `<animate>` 或在 `styles.css` 里给 class 加 CSS 动画。

## 3. 视觉语言（沿用，不要另起一套）

配色从 `ui/paper.js` 取（`import { C } from "./paper.js"`）：

| 变量 | 值 | 用途 |
| - | - | - |
| `C.PAPER` | `#e8dcc0` | 纸底 |
| `C.INK` | `#221d19` | 主墨色（标题） |
| `C.INK2` | `#40372d` | 次级墨 |
| `C.MUTED` | `#7e6f5c` | 说明文字 |
| `C.MUT2` | `#9c8e78` | 页脚小字 |
| `C.RED` | `#882e1f` | 印章红（唯一的强调色） |

字体栈：`KAI`（楷体，标题与叙述）与 `SONG`（宋体，数据与时间）。二者也从 `paper.js` import。**不要引入新字体文件**。

纸感直接复用 `buildDefs()` + `buildPaper(w, h)`：

```js
import { buildDefs, buildPaper, C, KAI, SONG } from "./paper.js";
let s = `<svg class="intro" viewBox="0 0 1600 1000" width="100%" height="100%">`;
s += buildDefs();          // 纸纹滤镜、暗角等 <defs>
s += buildPaper(1600, 1000); // 米黄纸底 + 污渍 + 纤维 + 暗角
s += `...你的内容...`;
return s + "</svg>";
```

排版基线（当前版本，可在此基础上调整）：桌面标题基线 y≈440、字号 168；手机标题 y≈410、字号 138。中文标题建议加 `letter-spacing` 12–20 做「刊头」感。

## 5. 如果要用 AI 生成的底图

两条路，任选：

- **内联（推荐）**：把图压到 200–400 KB 的 JPEG，转 base64 塞进 `ui/intro.js` 的 `<image href="data:image/jpeg;base64,...">`。优点：单文件、部署只需传 `dist/index.html`。缺点：包体变大。
- **走 /static**：把图片放项目根目录（如 `cover-bg.jpg`），SVG 里写 `<image href="/static/cover-bg.jpg">`，并把图片也上传到创空间仓库根目录。`/static/` 已由 `app.py` 挂载。缺点：多一个文件要传。

注意：**底图只做气氛，不要把正文压在复杂纹理上**。示例文字与印章必须保证在手机 390px 宽下仍可读。

## 8. 常见坑

1. **打包器是 IIFE 拼接**：`ui/intro.js` 里不要有和其它模块重名的顶层变量（`M`、`esc` 之类会被共享作用域里的名字盖住）。`esc` 在 `screen.js` 里也有，但各模块独立 IIFE，不冲突。
2. **SVG id 冲突**：`buildDefs()` 里已有 `grain / blotch / soft / vign / edgeShade` 这几个 id。你再加滤镜/渐变请换名字。
3. **SVG 元素没有 `.click()`**：应用层是用 `document` 上的事件委托，所以只要元素带 `data-act="start"` 就行，别自己绑事件。
4. **不要用 CSS 改 `#stage` 比例**：手机端的缩放由 `styles.css` 的 media query 控制，改 `viewBox` 才是正路。
5. **运行环境没有 Python 依赖**：别引入需要构建的资产（Sass、字体子集工具等），只写 SVG/CSS/JS。
