# 《第七夜》试玩说明（发给朋友用）

## 一句话
一个玩家、七天、最多六条规矩，关住一个每天夜里都在找漏洞的囚犯。

## 链接
https://modelscope.cn/studios/lxyovo/six-rules

手机可以直接玩（竖屏版式已适配）。电脑体验更好。

## 怎么玩（大约 6–10 分钟）
1. 一屏就是整局：左边是监狱平面图，右边是六条空白的规矩。
2. 点任意一条空白规矩，用一句人话写下来，例如「洗衣房的床单，夜里不许取走」。
   系统会当场把它译成一条能执行的条件，比如 `22:00–05:00 · 洗衣房 · 禁止取物 · 无例外`。写得越宽，狱警越不服从。
3. 点右下角的「入 夜」。夜里他只会走一步，第二天早上巡查报告会告诉你他去了哪。
4. 入夜前可以预判他今晚走哪条路，猜中多一点行动力。
5. 七天过去，出一张判决书：六条规矩原样列出，加一句判词，指出你哪条规矩漏了几次。

## 想请你反馈的 5 个问题（回 5 句话就行）
1. 第一分钟你知不知道自己要干什么？如果不知道，卡在哪？
2. 有没有哪一步让你犹豫或烦躁（写规矩 / 入夜 / 预判 / 读报告）？
3. 你觉得这个囚犯是「AI」吗？哪一刻最像 / 最不像？
4. 玩完想不想再来一局？为什么？
5. 用一句话形容这局游戏。
