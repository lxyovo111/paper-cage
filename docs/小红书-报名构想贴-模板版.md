**标题**：用 AI 造一款监狱小游戏，点开就玩

**【创意】** 面向「只有碎片时间、又想动点脑子」的玩家，做一款回合制策略小游戏，核心体验是：**你写下的每一条规矩，第二天都会被他拿来对付你**。背景设定：你是监狱长，七天，最多六条规矩，关住一个每天夜里都在找漏洞的囚犯。

**【玩法】** 玩家进入后先写第一条规矩——用一句人话，系统把它译成一条能执行的条件（「夜里任何人不得进入洗衣房」→ 22:00–05:00 · 洗衣房 · 禁止位移）。通过**写规矩 / 读第二天的巡查报告 / 入夜前预判他今晚走哪条路**，达成目标：七天内不让他走出这道门。一局约 8 分钟；失败条件是他找到一条没被规矩盖住的路，或者你规矩写得太宽，狱警先不干了。重复可玩性来自：每条规矩的宽窄都有代价、他一夜只走一步且会换路、四种结局称号（铁壁 / 空规矩 / 账本 / 记得）。

**【AI 工具计划】**

- 策划与代码：AI 编程 Agent（DeepSeek Harness）写了约九成代码；我定机制、砍功能、标数值
- 玩法内 AI：魔搭 API Inference（Qwen3.8-27B，关思维链）三处——编译判定条 / 在引擎漏洞清单里挑一条路 / 写一句囚犯的独白。**判定全归规则引擎，AI 只能提案**
- 美术：不用 AI 生图，CSS + 手写 SVG（纸张、墨线、红章），零外部素材
- 音频：暂无，静音
- 演示：浏览器录屏 + ffmpeg 拼 90 秒（含关 AI 的对照片段）

**【预期形式】** 网页 Demo 已部署魔搭创空间，手机竖屏可玩、不用注册；后续按试玩反馈迭代关卡与数值。
