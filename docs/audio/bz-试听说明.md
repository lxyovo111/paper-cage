# 声音试听小样

本组仅供试听：包含两段 36 秒配乐，以及印章、笔划、翻页、熄灯、脚步五段音效。由本目录 `make_audio.py` 使用 NumPy 按固定随机种子从数学波形与噪声合成；没有使用先前推荐的第三方配乐或真实录音。它们是合成示意，纸、笔和脚步目前并非真实采样，成品可根据试听反馈换成有明确授权的录音细化。

- 白天案卷：稀疏的钢琴式音色与长音，定位是思考、编写规矩。
- 夜间巡视：同一声部更稀疏、更低暗，定位是熄灯后观察他行动。
- 两段配乐均有淡入淡出，是短试听版本，不是已经处理好无缝衔接的循环文件。
- 音效分别为印章、笔划、翻页、熄灯、脚步；都是程序化拟音，目标是先确认气质和节奏。

本次未修改或部署游戏。任何后续接入须由项目负责人确认具体选曲、音量和场景；继续保持音乐、音效可独立关闭，并在玩家交互后再启动音频。代码独立运行所需依赖：Python、NumPy。
