## 录制方法（本机已具备）
- 用 tools/cdp.mjs 起 headless Edge，逐段截帧（1600×1000，deviceScaleFactor=2），ffmpeg 合成。
- 夜戏动画需真实 CSS 动画：每 250ms 抓一帧，连成短片。
- A/B 对比：同一 seed，两个页面分别 ?seed=7 与 ?seed=7&llm=0，只截第 4 夜。
- 无解说音轨时用字幕条承载全部文案（评委会静音看）。
